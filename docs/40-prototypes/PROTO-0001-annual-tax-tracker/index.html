PROTO-0001 · สมุดภาษีรายปี

ต้นแบบหน้าจอ (Direction B — Slate & Amber) ของ REQ-0001 / ANA-0001 เปิดแต่ละหน้าจอด้านล่าง ทุกหน้าเชื่อมกันผ่านเมนูด้านบนของหน้านั้นๆ ได้เลย ตัวเลขทั้งหมดเป็นข้อมูลตัวอย่าง

หน้าจอทั้งหมด
1. Dashboardภาพรวมปีภาษีที่เปิดอยู่ — รายได้/WHT สะสม, เพดานค่าลดหย่อนคงเหลือ, ประมาณการภาษี
2. บันทึกรายรับ-รายจ่ายฟอร์มบันทึกรายการ + ตารางรายการ พร้อม edit/history/void และ state ผิดพลาด
3. ค่าลดหย่อนกรอกค่าลดหย่อนแยกกลุ่ม พร้อมเพดาน 3 รูปแบบ (คงที่ / นับจำนวนคน / รวมกลุ่ม)
4. ตั้งค่าแก้ไขเพดานค่าลดหย่อน + อัตราภาษีขั้นบันได
5. สรุปปี / ปิดปีภาษีสรุปท้ายปี ปิดปี (พร้อม confirm) และตัวอย่างปีที่ปิดแล้ว (ล็อก)
