PROTO-0001 · สมุดภาษีรายปี

ต้นแบบหน้าจอ (Direction B — Slate & Amber) ของ REQ-0001 / ANA-0001 เปิดแต่ละหน้าจอด้านล่าง ทุกหน้าเชื่อมกันผ่านเมนูด้านบนของหน้านั้นๆ ได้เลย ตัวเลขทั้งหมดเป็นข้อมูลตัวอย่าง

หน้าจอทั้งหมด
0. เริ่มต้นใช้งาน (ครั้งแรก)เลือกโฟลเดอร์เก็บข้อมูล — แสดงครั้งเดียวตอนเปิดแอปแรกสุด (AC-18)
1. Dashboardภาพรวมปีภาษีที่เปิดอยู่ — รายได้/WHT สะสม, เพดานค่าลดหย่อนคงเหลือ, ประมาณการภาษี, ยอดทั่วไป
2. บันทึกรายรับ-รายจ่ายฟอร์มบันทึกรายการ (ภาษี/ทั่วไป) + ตารางรายการรายเดือน พร้อม edit/history/void และ state ผิดพลาด
3. ค่าลดหย่อนกรอกค่าลดหย่อนแยกกลุ่ม พร้อมเพดาน 3 รูปแบบ (คงที่ / นับจำนวนคน / รวมกลุ่ม)
4. ตั้งค่าที่จัดเก็บข้อมูล, แก้ไข/เพิ่ม/เก็บถาวรหมวดหมู่ค่าลดหย่อน + อัตราภาษีขั้นบันได
5. นำเข้า/ส่งออก (CSV)ส่งออกรายการ/สรุปภาษีเป็น CSV, นำเข้าไฟล์ backup กลับพร้อม preview ก่อนยืนยัน (AC-20–24)
6. สรุปปี / ปิดปีภาษีสรุปท้ายปี ปิดปี (พร้อม confirm) และตัวอย่างปีที่ปิดแล้ว (ล็อก)
